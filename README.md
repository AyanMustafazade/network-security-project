# Enterprise Network Design and Security Implementation

## Overview
Designed and implemented an enterprise network topology using Cisco Packet Tracer.

## Technologies
- VLAN
- VTP
- Router-on-a-Stick
- DHCP
- SSH
- Port Security
- DHCP Snooping
- NTP
- Cisco IOS

## Features
- VLAN segmentation for different departments
- Inter-VLAN routing using Router-on-a-Stick
- Secure SSH remote access
- DHCP address management
- Network security with Port Security and DHCP Snooping
- NTP time synchronization
